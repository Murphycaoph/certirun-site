# CertiRun Homepage Plan

## Homepage Job

The homepage should answer this buyer question quickly:

> Can CertiRun help me turn an unclear sourcing need into a structured RFQ, comparable supplier options, and a traceable execution path?

It should not read like a generic company profile or a product catalog.

## Recommended Section Order

1. Hero: RFQ-first sourcing value proposition
2. Primary CTAs: Start Sourcing and How It Works
3. Category triage: five sourcing categories
4. Buyer outcome blocks: compare, verify, coordinate, follow up
5. Visible process proof: examples of outputs buyers receive
6. Case pattern preview: evidence-led, not testimonial-heavy
7. Blog / Insights preview: sourcing guides that support buyer decisions
8. Final structured RFQ CTA

## Hero Message

The hero should emphasize:

- sourcing from China with less uncertainty
- requirement clarification before supplier comparison
- visible checkpoints during order coordination
- RFQ submission as the next action

## Evidence Types

Use proof formats that can be true without overclaiming:

- sample RFQ brief structure
- supplier comparison fields
- packing/document checklist examples
- dispatch update log examples
- anonymized communication patterns only when real and approved

## CTA Rules

- Primary CTA should lead to `/contact`.
- Secondary CTA should lead to `/how-it-works`.
- Blog CTA can point to `/blog`, but it should not distract from RFQ conversion.
