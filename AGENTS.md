## Project role

CertiRun is a broad China sourcing / procurement execution service website for industrial products. It is not a public SKU catalog and must not be turned into a messy product marketplace.

CertiRun should emphasize sourcing execution, RFQ handling, supplier coordination, specification clarification, comparison, inspection coordination, shipment follow-up, and buyer-side clarity.

## Allowed work

Codex may:

- adjust Astro page structure
- create or revise Services / Industries / How It Works / Cases / About / Contact pages
- improve navigation and internal links
- generate restrained English page drafts
- create or update content collections
- improve reusable components if aligned with the research documents

## Prohibited work

Codex must not:

- invent real customer cases
- claim CertiRun is an official authorized agent
- invent certifications, stock, prices, lead times, factory relationships, or inspection results
- copy supplier or competitor marketing copy
- turn CertiRun into a general SKU database or e-commerce store
- make production code changes without summarizing affected files first
